# PostgreSQL MCP Server

A Model Context Protocol (MCP) server that provides secure access to PostgreSQL databases, designed specifically for ACM (Advanced Cluster Management) search databases. This server enables AI assistants and other MCP clients to query and analyze database content through a standardized interface.

__This code has been generated by AI__

## Features

- **Full PostgreSQL Support**: Execute SQL queries with parameter binding and result formatting
- **Database Introspection**: List tables, describe schemas, and search table structures
- **Multiple Transport Modes**: Support for both stdio (CLI) and HTTP server modes
- **Security**: Parameterized queries prevent SQL injection attacks
- **Performance**: Configurable row limits and query optimization
- **Observability**: Built-in health checks, statistics, and logging

## Available Tools

The server provides the following MCP tools:

- `query_database` - Execute SQL queries with optional parameters and row limits
- `get_database_stats` - Retrieve database statistics (table count, rows, size, connections)
- `list_tables` - List all tables with row counts and schema information
- `describe_table` - Get detailed table schema including columns, types, and constraints
- `get_table_data` - Sample data from specific tables
- `search_tables` - Search for tables by name pattern

## Protocol Support

### MCP Protocol Versions
- **Primary**: Streamable HTTP (2025-03-26) 
- **Legacy**: Server-Sent Events (2024-11-05)

### Transport Modes
- **stdio**: Direct MCP client integration via stdin/stdout
- **HTTP**: RESTful API and MCP over HTTP (not working yet)
- **SSE**: Server-Sent Events for real-time communication
